# Changelog

## 0.2.0 - 2026-10-10

- Add independent column filters with nested AND/OR conditions, value selection, type overrides, and multi-column sorting.
- Detect header icons with 89 concepts and 668 aliases; persist custom synonyms and icon choices across files in the same browser.
- Show image thumbnails and hover previews, hex color swatches, readable dates, and muted placeholders for empty cells.
- Improve domain detection so numeric values and filenames are not mistaken for websites.
- Cap default column widths at 320px while retaining manual resizing and full-text hover previews.
- Keep all filtering, sorting, and display formatting separate from the original CSV values.

Versioning uses PHASE.MAJOR.MINOR: phase 0 remains the development phase; the feature update increments MAJOR from 1 to 2.

## 0.1.0 - 2026-09-26

- Initial public release of Folium's browser-based CSV inspection workspace.
- Position Folium as a place to review datasets produced through AI-assisted research; the paired agent handles collection and enrichment.
